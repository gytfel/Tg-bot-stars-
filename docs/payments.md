# Предложение по приёму оплаты

Документ отвечает на три вопроса: какие способы оплаты подключить, во что это
обойдётся и что уже готово в коде. Тарифы указаны как ориентир на момент
написания — перед подключением сверьтесь с актуальными условиями провайдера.

---

## 1. Варианты

### A. Telegram Stars (⭐, валюта XTR)

Встроенная валюта Telegram. Покупатель платит звёздами прямо в чате, кнопкой.

| | |
|---|---|
| Что нужно | Ничего: ни договора, ни юрлица, ни провайдера |
| Срок подключения | 5 минут (одна переменная в `.env`) |
| Комиссия | Пользователь покупает звёзды через App Store / Google Play, там ~30 % уходит платформе. На Fragment — дешевле |
| Вывод денег | Через [Fragment](https://fragment.com) в TON, после холда ~21 день |
| Возвраты | Автоматически, командой `/refund <номер заказа>` — уже реализовано |
| Ограничение | По правилам Telegram звёздами продают **цифровые** товары и услуги. Для физических товаров нужен обычный платёжный провайдер |

**Кому подходит:** доступ в закрытый канал, консультации, файлы, подписки,
курсы, услуги, донаты, внутриигровые предметы.

### B. Карты и СБП через Telegram Payments (ЮKassa и другие)

Классический счёт в чате: покупатель платит картой, деньги приходят на
расчётный счёт.

| | |
|---|---|
| Что нужно | ИП или ООО, договор с провайдером, токен от `@BotFather → Payments` |
| Срок подключения | От 1–3 дней (модерация провайдера) |
| Комиссия | Ориентировочно 2,8–3,5 % с карты, СБП заметно дешевле |
| Вывод денег | На расчётный счёт, обычно на следующий рабочий день |
| Возвраты | В личном кабинете провайдера |
| Ограничение | Продажа физлицам в РФ — это 54-ФЗ: нужна онлайн-касса и чеки (провайдеры продают это как услугу) |

**Кому подходит:** физические товары, любой оборот, где нужна «белая» касса.
Самозанятым большинство провайдеров карточный эквайринг напрямую не даёт —
уточняйте отдельные тарифы для самозанятых.

### C. Перевод на карту / по СБП вручную

Покупатель переводит по реквизитам, админ подтверждает заказ руками.

| | |
|---|---|
| Что нужно | Ничего |
| Комиссия | 0 % |
| Минусы | Ручная сверка каждого платежа, нет автоподтверждения, банки не любят регулярные входящие переводы от незнакомых людей, налоговые риски |

**Кому подходит:** самый старт, десяток заказов в месяц, проверка спроса.

### D. Оплата при получении

Уже работает, комиссий нет. Минус — невыкупы; для доставки курьером или
самовывоза нормальный вариант.

## 2. Что рекомендую

**Если товар цифровой (доступ, файлы, услуги, подписка) — Telegram Stars.**
Ноль бюрократии, оплата в два тапа, возвраты автоматом, всё уже написано в коде.
Включается одной строкой в `.env`. Минус один — комиссия платформы внутри цены
звёзд, поэтому закладывайте её в прайс через `STARS_RATE`.

**Если товар физический — ЮKassa (или другой провайдер Telegram Payments).**
Звёзды здесь нельзя по правилам площадки. Пока идёт оформление ИП и договора,
работайте на «при получении» + «перевод на карту»: это уже включено и не требует
ничего.

**Комбинация, которую советую на первый месяц:**

1. Сегодня: «при получении» + «перевод на карту» — можно принимать заказы сразу.
2. Параллельно: если товар цифровой — включаем Stars (5 минут, см. ниже);
   если физический — подаём заявку в ЮKassa.
3. Когда придёт токен провайдера — вписываем его в `.env`, перезапускаем бота,
   кнопка «💳 Онлайн-оплата» появляется сама.

### Прикидка по деньгам

Оборот 100 заказов × 1 000 ₽ = 100 000 ₽:

| Способ | Комиссия | Остаётся |
|---|---|---|
| Перевод на карту | 0 ₽ | 100 000 ₽ (но всё вручную) |
| ЮKassa, карты ~3 % | ~3 000 ₽ | ~97 000 ₽ |
| ЮKassa, СБП | ~500–700 ₽ | ~99 300 ₽ |
| Telegram Stars | комиссия платформы внутри цены звёзд + вывод через Fragment | зависит от того, как покупатель купил звёзды |

Вывод: СБП — самый дешёвый безнал для физических товаров; Stars выигрывает не
ценой, а тем, что подключается мгновенно и без документов.

## 3. Что уже готово в коде

| Возможность | Статус |
|---|---|
| Оплата при получении | ✅ работает |
| Перевод на карту | ✅ работает |
| Счёт в Telegram Stars (XTR, одна позиция, целые звёзды) | ✅ реализовано |
| Счёт через провайдера (RUB и другие валюты, суммы в копейках) | ✅ реализовано |
| Заказ создаётся как «⏳ Ожидает оплаты», склад и корзина не трогаются до оплаты | ✅ |
| Проверка `pre_checkout` (заказ существует и не оплачен) | ✅ |
| Повторное уведомление об оплате не создаёт второй заказ и не списывает склад дважды | ✅ |
| Возврат звёзд командой `/refund <номер>` | ✅ |
| Кнопка «Онлайн-оплата» прячется, если оплата не настроена | ✅ |
| Чеки по 54-ФЗ | ❌ делается на стороне провайдера при подключении кассы |

### Как включить Stars

```env
PAYMENT_CURRENCY_CODE=XTR
PAYMENT_PROVIDER_TOKEN=
STARS_RATE=2.0        # сколько рублей прайса приходится на 1 ⭐
```

Товар за 890 ₽ при `STARS_RATE=2.0` превращается в счёт на 445 ⭐.
Курс подбирайте так, чтобы после комиссий оставалась нужная сумма.

### Как включить карты

```env
PAYMENT_CURRENCY_CODE=RUB
PAYMENT_PROVIDER_TOKEN=390540012:LIVE:xxxxxxxx
```

Токен берётся в `@BotFather → /mybots → ваш бот → Payments → выбрать провайдера`.
У провайдеров есть тестовые токены (`:TEST:`) и тестовая карта
`4242 4242 4242 4242` — прогоните на них полный цикл до включения боевого.

После смены `.env` — перезапуск: `sudo systemctl restart shopbot`
(или `docker compose up -d`). Проверить, что бот увидел настройки:
`python doctor.py` — он покажет, какой способ оплаты активен.

---

## 4. Что решить вам

1. Товар цифровой или физический — от этого зависит, Stars или провайдер.
2. Есть ли ИП/ООО (или планируется) — без этого карточный эквайринг не подключить.
3. Какой курс звезды закладываем в прайс (`STARS_RATE`), если идём в Stars.
